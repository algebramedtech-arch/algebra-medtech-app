# ALGEBRA MedTech mobile app prototype

## Files
- `index.html`: responsive app interface
- `manifest.json`: installable PWA metadata
- `sw.js`: offline cache support when hosted over HTTPS

## Install on Android
1. Upload these three files to an HTTPS static host (for example, a GitHub Pages site).
2. Open the published HTTPS URL in Google Chrome on your Android phone.
3. Tap ⋮ and choose **Add to Home screen** or **Install app**.
4. Launch ALGEBRA from the new home-screen icon.

## Important
This is a prototype. Anatomy and products are sample data only; there is no licensed 3D anatomy model, secure team login, cloud sync, or verified manufacturer catalogue. Local visit notes stay in that browser on that device. Do not use sample details for clinical or procurement decisions.
